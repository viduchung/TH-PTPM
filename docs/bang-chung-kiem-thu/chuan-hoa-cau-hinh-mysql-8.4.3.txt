Ghi chú: booking_db = script chung + V2 (BOOKING_DB_NAME=booking_db); r2_s5 = Hibernate tạo; ch_team_only = script chung chưa chạy V2;
         ch_empty = CSDL rỗng; ch_thieu_huy = đủ cột + pitch_locks nhưng ENUM status vẫn enum('cho_duyet','da_duyet','tu_choi')
→ validate KHÔNG kiểm tra danh sách giá trị ENUM.
